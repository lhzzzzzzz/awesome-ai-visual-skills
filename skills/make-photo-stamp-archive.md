# Make Photo Stamp Archive

[← Back to the English directory](../README_EN.md) · [Source repository](https://github.com/Dlcccc71913/skill-make-photo-stamp-archive) · [Author](https://github.com/Dlcccc71913)

Make Photo Stamp Archive creates a clean direct-splice composition: a faithfully preserved photograph sits beside warm-white paper containing a small, source-specific hand-pressed seal. The result works especially well with architecture, travel scenes, portraits, and quiet keepsakes.

The official example already contains the source photograph and its derived stamp in one landscape composite.

## Installation

```bash
git clone https://github.com/Dlcccc71913/skill-make-photo-stamp-archive.git
mkdir -p ~/.codex/skills
cp -R skill-make-photo-stamp-archive \
  ~/.codex/skills/make-photo-stamp-archive
```

Restart Codex if the Skill does not appear immediately.

## Example request

```text
Use $make-photo-stamp-archive to turn this photo into a direct-splice archival artwork with a custom seal.
Keep the photo panel unchanged and derive the seal only from the visible subject.
```

## Safety and privacy

- Use photos you own or are allowed to edit and republish.
- The host image editor may send the photograph to a third-party model provider; review its privacy terms before using family, client, or location-sensitive photos.
- Review `SKILL.md` and the prompt reference before installing. The repository does not require bundled scripts, API keys, or fonts.
- Inspect generated seals for accidental symbols, signatures, trademarks, or text before publication.
