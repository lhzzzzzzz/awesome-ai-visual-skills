# Photo Relic Editorial

[← Back to the English directory](../README_EN.md) · [Source repository](https://github.com/wnby/photo-relic-editorial) · [Author](https://github.com/wnby)

Photo Relic Editorial transforms a photograph into a vertical paper-memory artwork. The upper half preserves the real photograph while the lower half compresses structure, light, color, visual weight, and mood into a recognizable modern print with restrained Eastern negative space.

The example is an official finished composite with the source photograph and paper-memory print already arranged together.

## Best for

- architecture, landmarks, bridges, towers, and skylines;
- reflections, strong silhouettes, processions, crowds, and ordered scenes;
- photographs that can be distilled into shape, light, and a small palette.

## Installation

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/wnby/photo-relic-editorial.git \
  ~/.codex/skills/photo-relic-editorial
```

Restart Codex if the Skill does not appear immediately.

## Example request

```text
Use $photo-relic-editorial to turn this photo into a Photo Relic artwork.
Keep the photograph truthful and give the lower print a short four-character Chinese title.
```

## Safety and privacy

- Use original, licensed, or explicitly permitted photographs.
- Review the image provider's handling of uploads before using private or identifiable photos.
- The repository contains the Skill, prompt reference, metadata, and examples without required executable scripts; still inspect the complete instructions before installation.
- Check generated Chinese text and landmark names manually because image models can distort lettering or factual details.
